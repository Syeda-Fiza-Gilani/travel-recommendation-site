# ✈️ Travel Recommendation Website

A responsive travel site where you can search for destinations by keyword, country, or category. I built it to practice DOM manipulation and filtering data with JavaScript.

<img width="1608" height="889" alt="Travel Recommendation Website screenshot" src="https://github.com/user-attachments/assets/c5d47794-2fe3-4c80-b940-a20b96a1dab9" />

## Features
- Search destinations by keyword, country, or category
- Destination cards with images and short descriptions
- Clear button to reset the search and show everything again
- Responsive layout for desktop, tablet, and mobile

## Built With
HTML, CSS, vanilla JavaScript (ES6)

## What I Learned
- Filtering arrays and updating the page dynamically based on user input
- Handling events like search and reset
- Making a layout responsive with plain CSS

## Project Structure
- `index.html`: page structure
- `script.js`: search and filtering logic
- `style.css`: styling and responsive layout
- images: destination photos

## Run It
Clone the repo and open `index.html` in your browser.
